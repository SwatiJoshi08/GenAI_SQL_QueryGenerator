# GenAI-Powered Natural Language SQL Query Generator and Analyzer

A full‑stack monorepo that lets users describe what they want in natural language and receive **schema‑grounded**, validated, and safety‑checked SQL queries. The project includes:
- **Frontend** – React + Vite + TypeScript + Tailwind CSS UI.
- **Backend** – Node.js + Express + TypeScript (tsx for dev, Zod for validation).
- **Database adapters** for MySQL and PostgreSQL.
- Configuration via environment variables only.

This repository contains only the scaffolding; implementation of features will be added later.
